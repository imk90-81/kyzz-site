## 1️⃣ 🏛️ 白宫敲定前沿 AI 自愿安全测试框架，约谈四大巨头

**发生了什么**
白宫于美国时间周二（8/4）召集 **OpenAI、Google、Meta、Anthropic** 召开闭门会议，由国家网络总监办公室（ONCD）主持，敲定"前沿 AI 模型自愿安全测试框架"的落地安排。框架源自特朗普 **6 月 2 日签署的 AI 行政令**，已按 8 月 1 日期限完成制定。

**核心规则**

| 条款 | 内容 |
|:--|:--|
| 政府优先访问期 | 模型向可信合作伙伴开放前，最长 **30 天**（原定 90 天，业界游说后缩短） |
| 评估目的 | 判断模型是否可被用于发现软件漏洞、发起复杂网络攻击 |
| 执行机构 | 财政部、国家安全局（NSA）、网络安全和基础设施安全局（CISA） |
| 测试基准 | **保密**，白宫未公开具体指标 |
| 强制性 | ❌ 纯自愿，不设审批、不发牌照，政府**无权叫停**模型发布 |

**为什么值得关注**
这是美国 AI 治理从"倡议"走向"流程化"的第一个实质节点，且发生在多起模型沙箱逃逸事故之后。关键张力在于：**90 天 → 30 天的缩短，说明产业界议价能力仍显著强于监管方**；而"自愿 + 保密基准 + 无否决权"的组合，意味着它更像预警机制而非安全闸门。后续要看是否有企业实际提交模型、以及框架会否被写入强制立法。

📰 来源：CNBC（白宫官员匿名证实）、腾讯网、企鹅号新闻蒸馏器

## 3️⃣ 🦾 Google DeepMind 发布 Gemini Robotics 2：人形机器人"从脚趾到指尖"全身控制

**发生了什么**
7 月 30 日，DeepMind 推出新一代物理 AI 模型套件 **Gemini Robotics 2**，首次实现人形机器人**全身一体化集中控制**——打通双腿、躯干、双臂、灵巧手全部自由度，由同一模型统一调度。

**三款模型架构**

```
        ┌─────────────────────────────┐
        │  Gemini Robotics ER 2       │  ← 具身推理"高级大脑"
        │  环境理解 / 多步规划 / 多机协作 │     (已开放 Gemini API + AI Studio)
        └──────────────┬──────────────┘
                       │ 指令分派
        ┌──────────────▼──────────────┐
        │  Gemini Robotics 2 (VLA)    │  ← 视觉-语言-动作
        │  相机画面+自然语言 → 全身关节控制 │     (早期合作伙伴)
        └──────────────┬──────────────┘
                       │
        ┌──────────────▼──────────────┐
        │  Gemini Robotics On-Device 2│  ← 端侧本地运行，弱网可用
        └─────────────────────────────┘
```

**能力实测**
- 搭载 Apptronik **Apollo 2** 人形机器人演示：接到"把浇水壶放进底层货架的绿色垃圾桶"指令后，自主跨房间移动、避障、下蹲拾取、精准放置
- 精细操作：旋拧灯泡、密封包装袋；**官方测试拆灯泡成功率 92%**
- 执行中持续分析视频判断进度，**失败可自行修正或重试**，不需每步等新指令
- 跨机体通用：**数小时内**完成对新硬件适配

**为什么值得关注**
上一代只管上半身，这一代把"移动"和"操作"塞进同一个决策模型，直接冲击人形机器人行业长期的**分层控制架构瓶颈**（运动控制与操作控制两套系统割不开）。加上 ER 2 已通过 API 对开发者开放，DeepMind 实际在抢占"机器人通用大脑"的生态位——硬件厂做身体，模型层归谷歌。A 股机器人板块 8/3-8/4 连续两日拉涨，国证机器人产业指数 +2.3%。

## 4️⃣ 💻 AI Coding 价格战升级：从"跑分"转向"生态卡位"

**发生了什么**
一周内两记价格重拳：

| 时间 | 事件 | 价格 |
|:--:|:--|:--|
| 7/30 | OpenAI 大幅下调 GPT-5.6 价格（上市仅三周） | — |
| 7/31 | DeepSeek-V4-Flash **正式版 API** 上线公测 | 缓存命中 **¥0.02**/百万 token，未命中 ¥1，输出 ¥2 |

**DeepSeek V4-Flash 正式版要点**
- Agent 能力大幅增强，多项基准**远超预览版**
- 模型结构、尺寸与预览版一致，**仅重新做了后训练**
- 原生支持 **Responses API** 格式，并针对性适配 **Codex**
- 仅 Flash 版 API 升级；V4-Pro 的 API 及 APP/Web 端未变，正式版"尽快发布"

**为什么值得关注**
两个细节比降价本身更关键：① DeepSeek 主动适配 OpenAI 的 Responses API 和 Codex——**兼容对手的接口标准，是典型的生态卡位动作**，降低开发者迁移成本；② "结构不变、只改后训练就大幅提升 Agent 能力"，说明当前 Agent 能力瓶颈更多在训练数据与后训练方法，而非架构规模。价格战的真正战场已经从 token 单价转向**谁的接口成为事实标准**。

## 5️⃣ 🔓 MiniMax H3 开源，摩尔线程/壁仞/海光同日完成 Day0 适配

**发生了什么**
8 月 3 日，MiniMax 开源新一代**通用全模态生成系统 MiniMax H3**（支持图/文/音/视频全性能多模态交互与生成）。同一天，**摩尔线程、壁仞科技、海光信息**三家国产算力厂商同步宣布完成该模型的 **Day0 适配**，国内开发者可即刻在对应国产算力平台部署。

## 🔟 🔬 清华李勇团队 Nature + Science 双发：AI 加速个体，却让科学"集体窄化"

**发生了什么**
清华大学李勇团队在 **Nature 与 Science** 发表研究，提出并系统验证了 **"AI for Science 悖论"**。

**研究规模**

```
📚 分析文献        2.5 亿篇（跨越半个世纪）
📊 基准数据集      4130 万篇论文（1980–2025）
👥 覆盖研究者      2857 万人
🎯 AI 论文识别准确率  0.875
```

方法上摒弃关键词匹配，采用"**专家精标 + 大模型推理**"迭代路径，训练 BERT 类模型从标题摘要语义判断论文的"AI 成色"。

**核心结论（双面）**

| ✅ AI 带来的 | ⚠️ AI 造成的 |
|:--|:--|
| 显著加速科学家**个体**职业发展 | 科学共同体**探索广度系统性收缩** |
| 产出效率提升 | 研究**注意力惊人趋同** |
| 催生 AlphaFold 级里程碑 | **颠覆性成果比例反而下滑** |

**为什么值得关注**
这项研究给"AI for Science"叙事泼了必要的冷水：各基础学科的整体突破速率**并未出现预期中的范式革命式加速**。机制上很好理解——AI 工具让"已有方向上做得更快"变得极其廉价，从而在个体理性层面挤压了高风险探索的动机，最终形成集体层面的路径依赖。对科研管理、经费分配、以及 AI 工具产品设计（是否应主动引入多样性激励）都有直接政策含义。

📰 来源：Nature、Science（清华大学李勇团队）
