### 1. OpenAI 新模型 Astra 内测曝光，前端零样本生成能力跃升
- **事件概述**：OpenAI 扩大新模型 Astra（代号 `mozaik-alpha-fdm`）内测，开发者实测 Max 模式下零样本一次生成 3D 等距地图与交互网页。核心突破含**端到端多智能体编排、超长程任务保持、持久化推理与即时自我纠错**。
- **值得关注**：标志 LLM 从"对话/补全"向"端到端多智能体软件生产"跃迁，前端/游戏原型生成进入自动化拐点。
- **关键因素**：多智能体编排 · 持久化推理 · 生成中自我验证
- **来源**：今日头条「波动智能 8·31 AI 早报」、aistart.ai

### 2. OpenAI 终止向 Cursor 供应模型（SpaceX 600 亿美元收购驱动）
- **事件概述**：SpaceX 以 **600 亿美元**收购 Cursor 母公司 Anysphere 并完成交割，15 天后 OpenAI 启动"控制权变更"条款宣布终止直接供模；Astra 等新模型不再提供，缓冲期后开发者只能**自带 API Key**。
- **值得关注**：AI 工具链"模型供应商 vs 应用层"权力博弈显性化，SpaceX 借 GPU 舰队掌控 AI 编程入口。
- **关键因素**：控制权变更条款 · 600 亿美元收购 · 自带 API Key
- **来源**：今日头条、aistart.ai、dev.to

### 3. 腾讯混元发布 Hy4 preview，770B 参数开源上线
- **事件概述**：总参数 **770B**、激活 **49B**、上下文 **1M**，覆盖软件工程、办公分析、游戏开发与科研；163 名内部专家对 203 个工程任务盲测均分 **2.99**，略优于 GLM-5.3（2.92）与 Kimi K3（2.94）；在三维 Blaschke-Lebesgue 几何难题上将体积下界推进至 **0.41104**；已在 HuggingFace 与腾讯云 TokenHub 开源。
- **值得关注**：国产开源大模型在软件工程与前沿数学上对标国际，1M 上下文 + 开源形成生态杠杆。
- **关键因素**：770B/49B MoE · 1M 上下文 · 开源
- **来源**：腾讯研究院 AI 速递（搜狐）、今日头条

### 4. 谷歌发布 Gemini Omni 1.1，视频可延展至 40 秒
- **事件概述**：视频模型 Gemini Omni 1.1 Flash 可读取最多 10 秒前序视频续接生成，单次扩展 10 秒、**累计最高 40 秒**；新增首尾帧控制与最长 3 秒视频参考输入，360p 草稿模式吞吐较 720p 提升约 **60%**、成本约 **1/3**，成片支持 4K；已通过 Gemini API 与 AI Studio 开放。
- **值得关注**：长视频连贯生成与可控性提升，显著压低视频创作成本门槛。
- **关键因素**：40 秒延展 · 首尾帧控制 · 成本降 2/3
- **来源**：腾讯研究院 AI 速递

### 5. Anthropic 发布 MHS 标准，把 MCP 延伸到物理设备
- **事件概述**：继 MCP 之后，Anthropic 发布面向物理设备的 **Model Hardware Standard** 预览版，用统一翻译层解决仪器接口碎片化；安全阈值写入驱动底层拦截越界指令，推理层与执行层分离，提供在线指挥与离线连发两种模式。卡内基梅隆用其协调实验**提速约 3 倍**，QuEra 激光重锁从 150 秒压至 **6 秒、成功率 99.3%**，丹纳赫、AWS 等加入生态。
- **值得关注**：AI 从"软件接口（MCP）"走向"物理世界接口"，具身/实验室自动化走向标准化。
- **关键因素**：统一翻译层 · 安全阈值底层拦截 · 生态（CMU/QuEra/AWS）
