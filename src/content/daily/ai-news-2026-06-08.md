# AI领域每日动态 - 2026年6月8日

## 1. 英伟达发布RTX Spark超级芯片，正式进军PC市场

**事件内容**：6月1日，英伟达在GTC Taipei 2026大会上发布面向Windows系统的全新超级芯片RTX Spark，采用Blackwell RTX GPU，拥有6144个CUDA核心和第五代Tensor Core。黄仁勋表示，今年秋季起，戴尔、联想等主流PC品牌将陆续推出搭载该芯片的笔记本及台式机。

**值得关注的原因**：标志着英伟达正式挑战英特尔与AMD在PC处理器市场的长期垄断地位，PC正从云端AI的访问终端转变为Agent工作的本地入口。

**关键因素**：
- 与微软合作，适配Windows ARM架构
- 联合联发科共同研发，集成处理器与显卡
- Agent时代推动PC重新靠近AI产业链核心

**新闻来源**：腾讯网、新浪财经

## 2. 云知声发布2660亿参数通用大模型U2

**事件内容**：6月8日，云知声（09678）正式发布新一代自研通用大语言模型U2，采用快慢思考融合的MoE混合专家范式架构，以2660亿参数规模实现顶级水准性能。模型以"智能密度×Token价值"为核心逻辑，为原生Agent驱动大模型。

**值得关注的原因**：国产大模型在参数规模和技术架构上的新突破，聚焦提升单位Token有效知识承载量与业务产出价值。

**关键因素**：
- MoE混合专家架构实现高效能
- 全栈开发、智能编排与深度推理一体化
- 高精度数据提纯与高密度语义表征

**新闻来源**：新浪财经

## 4. 中国人形机器人价格大幅跳水，松延动力发布9998元消费级机器人

**事件内容**：6月4日，松延动力发布的"小布米"(Bumi)人形机器人定价9998元，身高约94cm，体重约12kg，自由度不小于21个，主要面向C端家庭的教育、陪伴场景。补贴后售价已低至9418.1元。宇树科技的人形机器人也降至2.99万元。

**值得关注的原因**：人形机器人从百万元级迅速降至万元级，标志着产业化加速和消费级市场开启。

**关键因素**：
- 供应链成熟和规模化生产降低成本
- 核心零部件（伺服电机、减速器）国产化
- 从B端工业应用向C端消费场景渗透

**新闻来源**：腾讯网（腾讯新闻）

**关键因素**：
- 降本增效，减少API租赁成本

- GitHub Copilot将迎来新动力

## 10. 全球首个"预制算力中心底座"在山东青岛正式投用

**事件内容**：6月6日，全球首个预制算力中心底座在山东青岛正式启用，相较于传统算力中心节约施工周期近70%，为当前算力基础设施建设提供更高效、更低碳的新方案。

**值得关注的原因**：算力基础设施建设进入模块化、预制化新阶段，大幅降低AI算力部署门槛和成本。

**关键因素**：
- 施工周期缩短70%
- 模块化设计，可快速复制部署
- 低碳环保，符合AI能耗优化趋势

**新闻来源**：现代AI新闻早班车（腾讯新闻）
