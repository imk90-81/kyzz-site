二、核心产品深度分析

1. ChatGPT（OpenAI）

定位通用 AI 超级应用
用户规模全球 MAU ~9.58 亿；美国桌面 UV 3386 万；周活 8-9 亿
旗舰模型GPT-5 / GPT-5.2
上下文窗口256K tokens
Agent 能力GPTs（自定义 Agent）+ Operator（浏览器操作）+ 插件生态
多模态文本 / 图像（DALL-E）/ 语音 / 视频（Sora）
定价免费 / Plus $20/月 / Pro $200/月 / Team & Enterprise 定制
技术亮点GPT Store 数十万个自定义 GPT；Operator 可操控浏览器；Sora 视频生成
核心优势生态最完整、多模态最强、用户基数最大、插件最丰富
主要短板Pro 版昂贵（$200/月）；产品日趋复杂；无明确团队项目空间

2. Claude（Anthropic）

定位安全优先的 AI Agent 平台，编程与专业场景见长
用户规模全球 MAU ~3017 万（+28.39% MoM）；美国桌面 UV 266 万（+130.1% MoM）
旗舰模型Claude Opus 4.8
上下文窗口1M tokens
Agent 能力Computer Use · Claude Code（年收入 $25 亿+）· Dynamic Workflows · Agent Skills 开放标准
定价免费 / Pro $20/月 / Team $25/月 / Enterprise 定制
核心优势编程能力业界最强；超长上下文真实可用；安全性最佳；Agent 开放标准引领者
主要短板多模态弱（无原生图像/视频生成）；用户总量仍远低于 ChatGPT

3. 扣子（Coze，字节跳动）

定位全栈 AI Agent 工作台，多人多 Agent 协作
版本扣子 3.0（2026.6.1 上线）
Agent 能力项目空间 + 多人多 Agent 协作 · 编程项目 · 视频项目（剧本-分镜-生成-导出剪映）· 云端 + 本地 Agent 混合协同
生态技能商店 200+ 行业技能包；支持接入本地 Claude Code 等第三方 Agent；飞书 / 微信跨渠道共享记忆
定价免费为主
核心优势Agent 协作平台化最成熟；编程 + 视频双项目类型独有；三端协同体验最佳
主要短板国际化起步阶段；依赖字节生态；纯个人用户可能觉得功能过重

4. Gemini（Google）

定位多模态 AI Agent 平台，Google 生态核心
用户规模全球 MAU ~1.39 亿；美国桌面 UV 1066 万（+29.1% MoM）
旗舰模型Gemini 2.5 Pro
上下文窗口2M tokens（行业最大）
Agent 能力Computer Use · Antigravity Agent 开发平台 · MCP 原生支持 · Notebooks
定价免费 / Pro $20/月
核心优势多模态能力最强；上下文窗口最大；Google 生态深度集成；MCP 标准推动者
主要短板产品矩阵分散；Agent 自动化深度不及 Claude

5. 豆包（字节跳动）

定位多模态 AI 助手，覆盖写作 / 编程 / 学习等全场景
用户规模全球 MAU ~3.36 亿，中国第一
Agent 能力与扣子（Coze）生态联动
定价免费为主
核心优势用户量国内绝对领先；字节生态加持；C 端产品体验成熟
主要短板Agent 自主编排能力弱于专业 Agent 平台；国际化程度有限

6. 千问（阿里）

定位全栈 AI Agent 基座，模型生态 + 企业级部署
用户规模全球 MAU ~2.20 亿，增速 553%
Agent 能力千问云全面 Skill 化 / CLI 化；150+ 模型 API；MCP 多智能体协作
定价免费 / 企业定制
核心优势模型生态最丰富；企业级安全合规；阿里生态深度集成
主要短板C 端个人体验不如豆包；偏开发者与企业用户

7. DeepSeek

定位高性能开源模型驱动的 AI 智能助手
用户规模全球 MAU ~1.39 亿，中国第二
Agent 能力以对话式 Agent 为主，推理能力突出
定价免费
核心优势推理能力强；开源生态活跃；性价比极高
主要短板多模态能力弱；Agent 编排平台缺失；商业化起步阶段

8. 腾讯元宝

定位DeepSeek+ 智能新体验，腾讯生态 AI 入口
用户规模全球 MAU ~1.11 亿；DAU 超 5000 万
Agent 能力集成 DeepSeek 模型；微信 / QQ 生态联动
定价免费为主
核心优势腾讯生态流量加持；与 DeepSeek 深度整合
主要短板自研模型能力待验证；Agent 能力仍以对话为主

9. Manus AI

定位全球首款通用 Agent，自然语言驱动全场景自动化
用户规模全球 MAU ~211 万（+24.63% MoM）
Agent 能力内置虚拟 Ubuntu 系统；多模型动态路由；无限步骤工作流；跨网页 / 跨软件自主操作
核心优势零代码上手；虚拟系统提供真实操作环境；单任务自动化能力极强
主要短板用户规模小；无团队项目空间；依赖第三方模型

10. Perplexity

定位研究型 AI 搜索 + Agent 平台
Agent 能力Perplexity Computer · 19 模型协同调度 · Comet 浏览器双模式 · Mac 原生集成
定价免费 / Pro $20/月 / Max $200/月
核心优势搜索 + 引用体系最强；多模型调度最灵活；Mac 原生深度集成
主要短板用户规模偏小；仅 Mac 桌面端深度支持

11. Grok（xAI）

定位实时社交数据驱动的 AI 助手
用户规模全球 MAU ~7600 万
定价免费 / SuperGrok $30/月
核心优势实时社交数据独有优势；进化速度最快
主要短板非开放平台；Agent 自主编排能力弱

12. Kimi（月之暗面）

定位超长文本处理 AI 助手
用户规模全球 MAU ~2533 万
上下文窗口200 万字（约 400K tokens）
定价免费为主
核心优势超长文本处理标杆；学术场景口碑好
主要短板多模态能力弱；Agent 编排能力有限

五、2026 下半年展望

  1. Agent 标准化加速MCP 协议和 Agent Skills 标准将推动跨平台 Agent 互操作性
  2. 多 Agent 协作成为标配从单一 Agent 到「蜂群式」多 Agent 协作是明确趋势
  3. 端侧 Agent 崛起本地系统控制（Computer Use）+ 云端推理混合模式将成为主流
  4. 垂直 Agent 深化法律、金融、医疗等垂直场景 Agent 将出现标杆产品
  5. 中国市场格局豆包 + 千问双雄稳固，扣子 Agent 平台化路线差异化明显

AI Agent 正从概念走向普及。选择对的平台，比选择最强的模型更重要。
